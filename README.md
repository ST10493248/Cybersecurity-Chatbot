# Cybersecurity-Chatbot
Cybersecurity Awareness Chatbot
This project is a Cybersecurity Awareness Chatbot that was created as part of an academic portfolio. This application will be a game-changing online safety interactive learning tool for South African citizens, teaching them about online safety, phishing scandals, protecting their passwords, protecting their privacy, and safe online browsing.
Project Name: Cybersecurity Awareness Chatbot
Platform: WPF
Framework: Net 6.0
Language: C# / XAML
In this application, the console-based chatbot from part 1 is converted to a modern professional Graphical User Interface (GUI) application with Windows Presentation Foundation (WPF). The chatbot is programmed to recognize keywords that relate to cybersecurity and to generate random responses, keep it conversational, remember user information, detect the user's sentiment, and respond with empathy.
What have I implemented:
•	A WPF Windows Presentation Foundation application that is complete
•	The professional sidebar navigation with topic buttons.
•	Chat with messages that are displayed in real-time.
•	User messages are written in cyan colour.
•	Bot messages will be in light green.
•	Sentiment detection messages are displayed in yellow italic text.
•	ASCII Art works are perfectly translated from console to GUI.
•	Greeting dialog box when the GUI starts up, via voice.

When it comes to sentiment detection, I've added a few:
•	Worrying - detected from words: worried, scared, anxious, concerned, nervous, and offers safety advice to the child in an empathetic manner
•	Curious - identified by words: curious, interested, fascinated, want to learn
•	Encourages and provides ideas
•	Frustrated - seen in words: frustrated, annoyed, angry, fed up, tired of
•	Listens and understands and gives simplified answers
•	Confused - made out of words: confused, don't understand, unclear, complicated.
•	Gives clear explanations and basic tips in response
•	Happy - detected by words: happy, great, good, excellent, awesome
•	Uses positive reinforcement in response
•	Thankful - identified through words: thank, appreciate, grateful
•	Responds with gratitude acknowledgment
Memory and Recall
•	Stores user name after collection
•	Stores user interests when topics are discussed
•	Maintains conversation history list
•	Tracks the current topic being discussed
•	Records session start time
•	"memory status" command displays all stored information
•	"What do you remember?" command recalls user interests
•	Personalised responses using stored user name
